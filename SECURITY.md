# Security Policy

ClickTrace can inspect sensitive network information by design. Please treat captured data as confidential.

## Reporting a vulnerability

If you discover a security vulnerability in the extension, avoid publicly disclosing exploit details before the issue has been reviewed.

Contact the maintainer through:

https://github.com/dev-maegor

Include the affected component, reproduction steps, potential impact, and any relevant technical details. Do not include real credentials, tokens, private URLs, or personal data.
