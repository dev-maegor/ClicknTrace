# Contributing to ClickTrace

Thanks for helping improve ClickTrace Network Inspector.

## Guidelines

- Keep changes focused on developer-oriented network inspection.
- Avoid unnecessary permissions.
- Do not introduce remote executable code.
- Test debugger attach/detach behavior.
- Test both successful and failed network requests.
- Test pages with dynamic background traffic.
- Update the README when user-visible behavior changes.

## Pull requests

Describe what changed, why it was needed, and how you tested it.

For network-capture changes, include the types of websites/request patterns tested when possible.

## Bug reports

Include the Edge version, ClickTrace version, affected site type, reproduction steps, and expected vs. actual behavior.

Never upload captures containing passwords, cookies, access tokens, API keys, or other sensitive information.
