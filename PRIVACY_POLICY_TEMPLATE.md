# ClickTrace Network Inspector — Privacy Policy

ClickTrace Network Inspector is designed to inspect network activity locally in the user's Microsoft Edge browser.

## Data collection

The extension does not transmit captured network data to a developer-controlled server.

While recording, the extension may locally process network metadata exposed by the browser, including request URLs, HTTP methods, headers, status codes, timing information, initiators, and request bodies when the browser exposes them.

The extension may also process information about the webpage element clicked by the user, such as its tag, visible text, id, classes, and page URL.

## Data storage

Captured data is kept in the extension's runtime memory unless the user exports it. Exported JSON files are saved by the user through the browser's normal download mechanism.

## Sensitive information

Network requests can contain credentials, tokens, personal information, or other sensitive data. Users should not share exported captures containing such information.

## Third parties

The extension does not sell captured data or transmit it to third parties.
